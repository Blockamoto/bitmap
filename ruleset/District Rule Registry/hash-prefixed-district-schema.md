# Hash-prefixed District schema

**Default:** `0`  
**Introduced:** 3 June 2023

## Definition

When enabled, accept exact `#<height>.bitmap` as an alternative District schema.

## History

- **3 June 2023:** The early inscription tutorial used the hash-prefixed example.
- **14 June 2023:** The tutorial example was corrected.
- **16 June 2023:** The verification guide explicitly rejected `#69.bitmap`.

## Evidence

- [3 June GitBook revision](https://gitbook.bitmap.land/~/revisions/AZO0a8slhI90dZCq0SNg/)
- [Historical verification guide](https://github.com/Blockamoto/gitbook/blob/d541a50ee13da4637c38a77b9f8b69a541a741a1/archive/_old/bitmap-theory-101/how-to-verify-blocks.md)

## Clarifications

- This was a retracted documentation typo, not the intended canonical schema.
- When enabled, it is an alternative to the canonical format, not an additional simultaneous requirement.
